How to use these notes

cells

Each grey box is a code cell with its saved output underneath, exactly as Python produced it. Press ▶ run to run it live, ✎ edit to change the code (Shift+Enter runs), and ⏫ run all above if a cell needs variables from earlier ones.

live Python

The first run downloads Python (about 10 MB, then cached) — give it a few seconds. All cells on a page share one namespace, like one notebook. The pill in the corner shows its state; restart clears every variable.

labs

Dark-headed panels are hands-on labs: bytecode viewer, speed races, attribute lookup diagrams, a decorator stack builder, a generator stepper. Click around — you can't break anything.

colour key

blue plain-English explanations · coral common traps · yellow key ideas · green worth knowing: analogies, real timings and practical advice. Cells labelled extra go one step further than the basics.
