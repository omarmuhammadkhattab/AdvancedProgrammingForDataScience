Special methods

__str__, __repr__, __eq__
class Person:
    def __init__(self, name, age):
        self.name, self.age = name, age
    def __str__(self):            # print(p), str(p), f"{p}"
        return f"{self.name}, {self.age}"
    def __repr__(self):           # repr(p), Out[], lists
        return f"Person({self.name!r}, {self.age})"
    def __eq__(self, other):      # p1 == p2
        return (self.name, self.age) == (other.name, other.age)

decorator template
import functools

def my_decorator(fun):
    @functools.wraps(fun)
    def inner(*args, **kwargs):
        # before
        result = fun(*args, **kwargs)
        # after
        return result
    return inner

@my_decorator            # f = my_decorator(f)

metaclass template
class Registry(type):
    classes = {}
    def __new__(cls, name, bases, dct):
        new_class = super().__new__(cls, name, bases, dct)
        Registry.classes[name] = new_class
        return new_class

class Dog(metaclass=Registry):
    pass
type(Dog)          # __main__.Registry

Generators

generator function
def my_range(n):
    i = 0
    while i < n:
        yield i           # give a value, pause here
        i += 1

r = my_range(3)           # nothing runs yet
next(r); next(r); next(r) # 0, 1, 2
next(r)                   # StopIteration
for x in my_range(3): ... # for handles StopIteration

chapter 3 · 3.8
return vs yield

return gives one value and the function is finished. yield gives a value and the function pauses, keeping its local variables, until the next next(). A generator can be looped over only once.

chapter 3 · 3.8
A–Z

Glossary

bytecode

The low-level instructions Python compiles your code into before the Python Virtual Machine runs them.

GIL

Global Interpreter Lock: lets only one thread execute Python bytecode at a time in CPython.

class / instance

A class is the blueprint; an instance (object) is one thing built from it.

method

A function defined inside a class; its first parameter (self) is the object.

inheritance

A child class takes on the attributes and methods of its parent and can override them.

polymorphism

The same method name behaves differently for different types.

encapsulation

Restricting direct access to an object's data so it's changed only through its methods.

name mangling

Python renames __x inside class C to _C__x.

closure

An inner function that remembers variables from the function that created it.

decorator

A function that wraps another function to change its behaviour without editing it.

metaprogramming

Programs that create or manipulate other programs (or themselves).

metaclass

A class whose instances are classes. type is the default.

iterator

An object you can step through with next() one item at a time.

generator

A function that uses yield to produce an iterator, making values lazily.

MapReduce

Split a big job into map (process pieces in parallel) and reduce (combine results); the model behind Hadoop.
